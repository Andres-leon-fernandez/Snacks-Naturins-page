# Snacks-Naturin's Page

## Guía de Identidad Visual

Este proyecto sigue el Manual de Identidad Corporativa de Snacks-Naturin's, con el objetivo de mantener una comunicación visual coherente, profesional y alineada a la marca.

---

## Tipografía

La tipografía refuerza el carácter **cercano, profesional y amigable** de la marca.

### Títulos y contenido destacado

Usar la fuente **Amaranth** como reemplazo de _Congenial Heavy_.

```html
<h1 class="font-['Amaranth'] text-4xl">Hola Soy Título</h1>
```

**Uso recomendado:**

- Títulos principales (h1, h2)
- Secciones destacadas
- Mensajes importantes

---

### Texto general

Usar la fuente **Inter** como reemplazo de _National Park SemiBold_.

```html
<p class="font-['Inter'] text-xl">Hola como estás</p>
```

**Uso recomendado:**

- Párrafos
- Descripciones
- Contenido informativo

---

## Buenas prácticas tipográficas

- Mantener consistencia en el uso de fuentes
- No mezclar tipografías fuera de estas dos
- Respetar jerarquías visuales (títulos > contenido)
- Evitar uso excesivo de pesos innecesarios

---

## Paleta de colores

La paleta de Snacks-Naturin's está diseñada para transmitir:

### 🎯 Colores principales

- 🔴 Rojo (principal): `#E52619`
- 🟢 Verde (natural): `#98C01E`
- 🟠 Naranja: `#F1860B`
- 🟡 Amarillo: `#F2B707`
- 🟤 marrón: `#733702`

---

### 💻 Uso en Tailwind

```html
<!-- Rojo -->
<div class="bg-[#E52619]"></div>

<!-- Verde -->
<div class="bg-[#98C01E]"></div>

<!-- Naranja -->
<div class="bg-[#F1860B]"></div>

<!-- Amarillo -->
<div class="bg-[#F2B707]"></div>

<!-- Marrón -->
<div class="bg-[#733702]"></div>
```

---

## Buenas prácticas de color

- Usar fondos claros o neutros para mantener contraste
- No alterar los colores oficiales
- Evitar degradados no autorizados
- Mantener coherencia en toda la interfaz

---

## Importación de fuentes

Asegúrate de importar las fuentes antes de utilizarlas:

```html
<link
  href="https://fonts.googleapis.com/css2?family=Amaranth:wght@700&family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&display=swap"
  rel="stylesheet"
/>
```
